## 💻 Portfolio Projects

### 1. Role-Based Access Control (RBAC) & Permission Governance
* **Objective:** Implemented the AGDLP (Accounts, Global groups, Domain Local groups, Permissions) framework to create department network shares (e.g., Finance, HR) with restricted NTFS and Share permissions managed strictly through security groups.
* **IAM Concept:** Enforced the Principle of Least Privilege by eliminating explicit user-level permissions.
* **Portfolio Framing:** Documented how to remediate chaotic folder permissions by implementing a scalable, audit-ready RBAC architecture.

### 2. Automated Identity Lifecycle (JML Scripting)
* **Objective:** Developed a production-grade PowerShell suite for Joiners, Movers, and Leavers (JML). Built an automated provisioning script that ingests employee data to set up OUs, groups, and home folders, alongside a 1-click offboarding script that instantly revokes access, terminates active sessions, and archives the account.
* **IAM Concept:** Identity Lifecycle Management, automation, and regulatory compliance (SOC 2 / ISO 27001 SLAs).
* **Portfolio Framing:** Highlighted how automating identity lifecycles reduces manual provisioning errors to zero and mitigates insider threat risks during offboarding.

### 3. Privileged Access Management with Windows LAPS
* **Objective:** Deployed Windows Local Administrator Password Solution (LAPS) via Group Policy (GPO) to automatically generate, rotate, and encrypt unique local administrator passwords for domain-joined clients in Active Directory.
* **IAM Concept:** Privileged Access Management (PAM) and credential hygiene.
* **Portfolio Framing:** Showcased how eliminating static, shared local administrator passwords blocks lateral movement attacks and credential dumping.

### 4. Hybrid Identity Sync & Cloud Access Control
* **Objective:** Registered a free Microsoft Entra ID (Azure AD) tenant, installed Microsoft Entra Connect on the Domain Controller, synchronized on-premises domain users to the cloud, and enforced basic Multi-Factor Authentication (MFA).
* **IAM Concept:** Hybrid Identity Management, Cloud SSO, and Directory Synchronization.
* **Portfolio Framing:** Positioned as a modern IAM architect capable of bridging legacy on-premises infrastructure with cloud identity providers.
